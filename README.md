# Personal Assistant Bot

A command-line assistant bot for managing contacts.

## Features

- Add new contacts.
- Add phone numbers to existing contacts.
- Change phone numbers.
- Search for contact phone numbers.
- Display all contacts.
- Add birthdays to contacts.
- Show contact birthdays.
- Display upcoming birthdays for the next 7 days.
- Handle invalid input.
- Exit the application using close or exit.

## Technologies

- Python 3
- OOP
- datetime
- collections.UserDict

## How to run

```bash
python assistant.py
```
